# Nexus Arena — кибер-клуб

Одностраничный лендинг для кибер-клуба Nexus Arena.
Демо-проект для портфолио.

## Стек
- HTML5
- CSS3 (тёмная тема, графитовый фон и сдержанный оранжевый акцент)
- Vanilla JavaScript

## Демо
https://vanek2111.github.io/nexus-arena/

## Функционал
- Hero с статистикой
- Тарифы (4 варианта)
- Зоны клуба (4 зоны)
- Турниры (ближайшие события)
- FAQ (аккордеон)
- Форма бронирования
- Адаптив под мобильные
